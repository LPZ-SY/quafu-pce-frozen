## 结论
能说：
1. 6 比特、10 个 CZ、加单比特相位补偿的泡利关联编码电路，在 Baihua 真机上 20 题全部与模拟逐个读对（17–30 个决定/题）。
2. 按事先冻结的公平规则（按顺序 20 题、不挑题），真机上有纠缠电路的方案优于无纠缠电路：7 胜 1 负，p = 0.035。
3. 从 pce8（1/4）到 pce8c（3/4）再到 pce6（20/20）：先普查门相位、避开坏边、缩短链、补偿单比特相位，真机就能完整复现模拟。

不能说：
1. 有纠缠电路的优势没有超过"随机改同样个数的客户"到显著程度（p = 0.27）。所以能说"纠缠让电路能提出改动、比无纠缠好"，不能说"纠缠找到的改动明显比随便改动好"。
2. 真机结果与模拟完全相同，所以这次真机实验证明的是"硬件能准确执行"，有纠缠优于无纠缠的差别来自电路的表达能力（模拟中就存在），不是真机带来的额外收益。
3. 子问题小，经典方法可以直接穷举，不能说量子优于经典。
4. 20 题里只有 8 题分出胜负，样本小。
