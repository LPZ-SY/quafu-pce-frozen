## 一、训练诊断（K=2，种子 59001–59010）
| 检查 | 结果 |
|---|---|
| 从能复现最优的参数出发，按正式损失继续训练 | 10/10 留在最优（β=12 与 β=48 都是）：**损失函数没问题** |
| 固定 β=12（正式实验做法） | 单次命中最优 0.28，单次平均差距 0.53% |
| **β 分 6 阶段从 1.5 增到 48** | **单次命中 0.50，单次平均差距 0.19%** |
| 直接固定 β=48，同等步数 | 单次命中 0.12，单次平均差距 1.43% |

5 次取最好的命中率三者为 0.70 / 0.60 / 0.40（多阶段输出更集中）。
结论：瓶颈在训练路径；逐步加大 β 有效，好处来自"逐步"本身而不是最终值。仍低于经典直接调变量（正式实验单次 0.75）。

## 二、新出题方式检查（K=5，种子 60001–60030，纯经典）
规则（不看答案）：在所有"互为最近的 3 辆车"里取总装载率最高的一组（中位 0.94）；在最满的车里随机选一个客户，连同 3 辆车内最近的 4 个一起拿走；每人保留 16 个候选空位（80 个变量）；约 105 万种组合全部枚举。

| 指标 | 结果 |
|---|---|
| 最好插法经轻处理后比原方案短 | **0/30** |
| 最好插法经完整精修后比原方案短 | 2/30 |
| 最好插法中有客户换了车 | 8/30 |
| 后悔值插入没找到最好插法 | 2/30（这 2 题最好插法也不比原方案短） |
| "能变短"且"后悔值找不到" | **0/30** |

## 结论
在 8 个比特能容纳的插入子问题里（拿走 2–5 个客户、从已收敛的方案出发），改进空间几乎为零，经典后悔值插入几乎每次都已找到最好插法。证据链第 8 环（改善解质量）在这一规模上不成立，原因是问题本身，不是编码或训练。停止在这一方向上继续找子问题。
