# 泡利关联编码支线：来龙去脉（2026-10-11）

## 一、这条支线在做什么
- 整体流程：经典方法先给出完整派车方案；从中取相邻 3 辆车组成子问题交给量子电路；量子电路给出"哪些客户换车"的建议；最后经典方法做超载修正和局部精修。
- 子问题：3 辆车里每个客户一个二进制变量（1 = 换到最近的另一辆车，0 = 不动），共 17–30 个变量。训练用的目标是当前方案附近的二次近似（一次项 = 单个客户换车的路程变化，二次项 = 两个客户同时换车的相互影响，加超载惩罚）。
- 平台：Quafu 云平台超导芯片 Baihua、Shenglian、Dongling。
- 要回答：用泡利关联编码这种"省比特"的编码方式，能不能在真机上准确跑通，以及其中的纠缠有没有用。

## 二、为什么用泡利关联编码
- 一个变量一个比特需要 17–30 个比特，电路深，真机跑不准。
- 泡利关联编码（Sciorilli 等人）：n 个比特的两比特关联值 ⟨P_a P_b⟩（P 取 Z、X、Y 三种测量方向）共 3·n(n−1)/2 个，每个变量分配一个，变量取值 = 关联值的正负号。6 比特最多 45 个变量，8 比特最多 84 个。
- 这种编码依赖纠缠：没有纠缠时同一方向的关联值只是单比特期望值的乘积，能表示的正负号组合少得多。

## 三、电路与训练
- 电路：比特排成一条链，分层；每层先做单比特 RY、RZ，再在相邻比特间做 CZ（奇偶交替）。对照电路结构相同、去掉全部 CZ（无纠缠）。
- 训练全部在经典电脑上模拟：正负号放宽为 tanh(α·关联值)，代入子问题目标，梯度下降。真机只负责执行和读出（全 Z、全 X、全 Y 三种测量设置）。
- 为适应真机做的三处改动：
  1. 起点对齐：以随机初始参数下的正负号为"不换车"，训练从"不改动"出发；每换一个客户罚 0.05。
  2. 两段训练 + 间隔下限：第二段把绝对值小于 0.15 的关联值推离 0，避免真机噪声翻转正负号。
  3. 每题 3 个随机起点，取模拟中精修后缩短最多的一次；有纠缠和无纠缠用同一规则。
- 实现正确性已核对：电路模拟与稠密矩阵误差 1e−15；梯度与有限差分误差 1e−9；表达能力测试中有纠缠能复现 100% 目标正负号组合，无纠缠只能 67%–80%；复现原论文最大割结果。
