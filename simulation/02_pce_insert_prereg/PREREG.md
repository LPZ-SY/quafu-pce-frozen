## 一、要回答的问题
对同一个真实的带容量车辆路径插入子问题：
1. 泡利关联线路的连续优化，能否稳定地产生接近最优的离散方案？
2. 如果能，它相对于经典连续参数化（经典直接调变量）和经典插入启发式，增加了什么？

分两阶段：
- **第一阶段（K=2）：只检验机制**，即缺口 1、缺口 2、能否表达最优解。不检验对经典直接调变量的增量（预计会碰到天花板，见第七节）。
- **第二阶段（K=3）：检验增量。**第一阶段通过后才做。

## 二、实例与子问题
- 实例生成沿用 `pce_scale.py`：120 个客户，需求 1–10，容量 60，仓库居中；扫描法分车 + 搬一个、换一个，跑到收敛，作为起点。种子 **50001–50030**（未在本项目中用过），30 道题，按顺序全部使用，不挑选。
- 子问题：沿用 `pick_groups` 取最靠中间的 3 辆车。
- 拿掉客户：在这 3 辆车内，随机选一个客户及离它最近的 K−1 个客户（种子固定）。拿掉后，各车剩余客户的顺序按 `route_cost` 的结果固定下来。
- 空位：每辆车相邻两个停靠点之间（含进出仓库的两段）各一个空位。空位数 = 剩余客户数 + 3。
- 变量：x(客户 c, 空位 p)，共 K × 空位数个。8 个比特、二体编码，最多 84 个变量；超过时，每个客户只保留插入代价最小的若干空位，使总数不超过 84（记录是否发生裁剪）。

## 三、三个分数的定义
1. **软分数**：训练时真正最小化的连续值（定义见第四节）。
2. **硬解码分数**：每个客户取关联值最大的空位，在**车内顺序固定**的前提下精确计算插入后的路程变化，再加超载量。按枚举逐条重建路线核对，误差应 < 1e−9；若不一致，先修实现，不进入正式运行。
3. **轻处理后分数**：硬解码方案做超载修正（沿用 `evaluate` 的规则）+ 各车内部重排（`route_cost`）后的真实总路程变化。另外报告完整精修（搬一个、换一个，跑到收敛）后的结果，作为端到端的次要指标。

同一空位插入 3 人及以上：用惩罚项禁止；解码结果中出现的次数单独报告。超载修正前的超载率单独报告，不混入硬解码质量。

## 四、损失函数（软分数）
- 每个客户 c，对其候选空位的关联值 e(c,p) 取 softmax 得软分配 w(c,p) = softmax_p(β·e(c,p))。softmax 天然保证"每人只插一次"，因此不需要这一项惩罚。β 取 1.5 × 比特数（与原做法的放大系数同量级）。
- 路程项：Σ 插入代价(c,p)·w(c,p) + Σ（同一空位的客户对）修正项·w(c,p)·w(c′,p)。插入代价 = d(a,c)+d(c,b)−d(a,b)；修正项 = 两人插入同一空位时两种顺序中较短者的代价，减去两人单独插入代价之和。
- 超载项：每辆车期望装载 = 剩余需求 + Σ 需求(c)·w(c,p)；惩罚 = 系数 × Σ max(0, 期望装载 − 容量)²。
- 同一空位 3 人及以上：惩罚 = 系数 × Σ_p max(0, Σ_c w(c,p) − 2)²。
- 间隔项（第二段训练）：每个客户"第一名关联值 − 第二名关联值"不足 τ=0.1 时加惩罚；第一段训练不加。
- 距离按子问题内最大插入代价归一化。
- 各项系数在**种子 59001–59005**（不属于正式实例）上调好后冻结，正式运行不再调整。

## 五、对照组
| 组 | 内容 |
|---|---|
| Q | 有纠缠线路：8 比特链，每层 RY、RZ + 相邻 CZ（奇偶交替），层数 = max(4, ⌈变量数/8⌉) |
| P | 无纠缠门线路：同上，去掉全部 CZ，单独训练 |
| C1 | 经典直接调变量：每个变量一个参数，同一损失、同一解码、同一优化器（参数化见第十节第 1 条） |
| 枚举最优 | 全部组合逐一计算硬解码分数，取最优 |
| 后悔值插入 | 后悔值插入法（每次优先安排"插晚了损失最大"的客户） |
| 贪心插入 | 依次把每个客户插到当前代价最小的空位 |
| 随机 | 每个客户随机选空位，次数与 Q 的随机起点数相同 |

Q、P、C1 各 5 个随机起点，第一段 1000 步、第二段 500 步，Adam，学习率 0.05。初始化：线路参数在 [−π, π] 均匀取值；C1 的参数从均值 0、标准差 1 的正态分布取值。记录参数数量、目标函数计算次数、运行时间，作为计算预算的说明；"随机起点数相同"不等于"计算预算相同"。

## 六、指标与门槛

### 缺口 1：连续训练与离散解码的差距
- 每个实例内，Q 的 5 次运行（以及 Q、P、C1 合并）中，软分数与硬解码分数的秩相关；同时报告两者数值差。
- 方向统一为"越小越好"。某实例内硬解码分数全部相同时，秩相关无定义，记为"不可算"并报告个数，不计入中位数。
- **门槛 M1**：Q 的秩相关中位数 ≥ 0.7，且可算实例中至少 2/3 为正。

### 缺口 2：离最优解有多远
- 硬解码分数与枚举最优的差距（占起点总路程的百分比）；命中最优的比例。
- **门槛 M2**：Q 的 5 次取最好，在至少 50% 的实例上命中枚举最优，或与最优差距的中位数 ≤ 0.1%。
- 另外报告：对后悔值插入、贪心插入、随机的胜负；轻处理后与完整精修后的结果。

### 表达能力诊断（不作门槛，只作归因）
- 以枚举最优方案为目标，训练 Q 和 P 复现其"最大值位置"（每个客户关联值最大的空位就是最优空位，且领先第二名至少 τ）。每组 10 个随机起点、3000 步。
- 报告：复现成功的实例比例、复现所需步数。

### 第二阶段（K=3）增量门槛
- **I1**：在相同损失、解码、起点规则下，Q 对 C1 在"5 次取最好的最优差距"或"单次平均最优差距"上更好，逐实例配对，单侧符号秩检验 p < 0.05。
- **I2**：Q 对 P 同上。
- 同时报告三组的参数数量、计算次数、运行时间。

## 七、结论规则（事先写定）

### 第一阶段
| 观察 | 能支持的判断 | 不能推出的判断 |
|---|---|---|
| M1、M2 都通过 | 机制可行，进入第二阶段 | 量子有增量 |
| Q 和 C1 都有严重的软硬差距（M1 都不过） | 当前"连续放宽 + 最大值解码"组合有问题 | 线路有问题 |
| C1 通过、Q 不通过 | 优先检查线路的表达、优化方法、参数化 | 纠缠无用 |
| Q 通过、P 不通过 | 纠缠对所测线路族有帮助 | 量子优于经典 |
| Q 达到最优，但不优于后悔值插入 | 机制可行，尚无实际竞争优势 | 机制无效 |
| Q、C1 都在 ≥ 80% 的实例上命中最优 | **天花板：增量在 K=2 上无法识别** | 量子机制无效，或量子无增量 |

### 表达能力诊断的解读
- 复现成功：线路能表达该方案；若正常训练仍找不到，问题在训练。
- **复现失败不等于表达能力不足**：只能说"在本次的步数、起点数和复现损失下未复现"。可能原因还包括复现损失本身难优化、步数不足、起点不够。只有在加倍步数和起点数后仍失败，且 P 和 C1 的对应复现结果作为参照，才写成"表达能力可能受限"。

### 第二阶段
| 观察 | 判断 |
|---|---|
| I1、I2 都通过 | 在所测规模上，纠缠型参数化相对经典连续参数化有可测增量（仍不构成对经典启发式的优势，除非同时胜过后悔值插入） |
| I2 通过、I1 不通过 | 纠缠有助于所测线路族，但不构成量子优势 |
| 都不通过 | 在所测规模上没有可测增量 |

## 十、运行前补充说明（2026-10-11，正式实例 50001–50030 尚未运行）
以下改动都在看到任何正式结果之前写定：
1. **经典直接调变量的参数化**：改为 e(c,p) = tanh(参数)，参数从均值 0、标准差 1 的正态分布取值。原写法"e 直接作为参数"会让 β·e 在起点就远超线路关联值的范围（线路的关联值在 −1 到 1 之间），softmax 一开始就饱和、梯度几乎为零，对经典组不公平。改后两组的 e 范围相同，与项目以往的经典直接调变量写法一致。
2. **枚举最优不含同一空位 3 人及以上的组合**：与损失中禁止这种情况一致。
3. **实现正确性检查已通过**：K=2 的全部组合（784、484 个）上，损失公式与逐条重建路线的精确值最大误差 1.8e−15；K=3 中同一空位最多 2 人的 21924 个组合最大误差 7.1e−15；同一空位 3 人的 28 个组合误差 0.76（这类组合不精确，已被惩罚并从枚举最优中排除）。梯度与有限差分最大误差：对关联值 3.7e−8，对线路参数 6.8e−8。
4. **容量惩罚系数**：按事先写定的规则（TUNING_RULE.txt：Q 和 C1 解码无超载比例都 ≥ 0.9，取离最优差距平均最小者，平局取较小）在 59001–59005 上调定为 **0.5**（候选 0.5、1、2、5 的无超载比例都 ≥ 0.92），冻结。同一空位 3 人惩罚系数取 5，未调。
5. **"单次平均差距"中解码超载的运行**：记为该实例所有方法无超载运行中的最大差距（保守处理）；"取最好"只在无超载的运行中取。命中最优的判据：差距 < 1e−6%。
6. **表达能力诊断**：每个实例最多 10 个起点，一旦以领先第二名 ≥ τ 复现成功即停止；同时报告"复现最大值位置"与"且领先 ≥ τ"两种成功率。
7. **调参实例上的观察（不属于正式结果，不影响门槛）**：5 道调参题（系数 0.5）上，有纠缠线路取最好命中最优 3/5，经典直接调变量 5/5；单次平均离最优差距，有纠缠线路 0.64%，经典直接调变量 0.02%；在做了表达诊断的 1 道题（59001，计时运行）上，有纠缠和无纠缠线路都在 1 个起点内复现了最优方案。预登记的门槛、对照组和结论规则不因此改变。
