# 表达规范

- 全程使用中文表达，不要中英文混杂（例如不写“这个 block 的 proxy 能量”）。
- 专业术语第一次出现时，写成“中文名（英文原名，缩写）”，例如“量子近似优化算法（Quantum Approximate Optimization Algorithm，QAOA）”；之后统一使用同一个写法，不要换来换去。
- 业内通用的缩写（如 QAOA、QUBO、CVRP）在第一次定义之后可以直接使用。
- 不使用没有定义过的术语或自造词；如果必须引入新概念，先用一句话解释清楚。
- 同一个概念在整个项目中只用一个名字（例如统一叫“测量次数”，不要有时写“shots”、有时写“采样数”）。
- 代码中的变量名、函数名、文件路径保持原样，用反引号标出，不翻译。
