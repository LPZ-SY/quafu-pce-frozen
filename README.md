## 一句话结论
表达能力是真的，在国产超导真机上能稳定读出，并且有纠缠在真机上胜过无纠缠（pce6：7 胜 1 负，p = 0.035）；但在 6–8 个比特能容纳的子问题里，好答案本来就不需要这种能力，经典方法已经是最优，所以不能转化为更好的路线。完整证据链与边界说明见 `docs/01_答辩证据链_冻结_20261011.md`。

## 每个真机实验包的结构
- `gen_*.py`：生成题目、训练参数、输出线路（`circuits/`）与理想关联值（`ideal/`，部分包有）。
- `submit_*.py`：普查门相位、选链、正式检测、相位补偿、提交与收取结果。
- `edgecheck*.py`、`survey.py`：逐边门相位检测与普查。
- `analyze_*.py`：按预登记判据分析。
- `PREREG*.md`：运行前写定的判据。`task_manifest.json`：任务清单。`SHA256SUMS`：打包时的校验值。
- `live*/`：`ledger.json`（任务台账）、`run_log.txt`、提交时的芯片标定快照、`raw/`（实验返回）、`raw_check/`（正式检测返回）、`raw_survey/`（普查返回）。

## 运行环境
- 模拟：Python 3、`numpy`、`numba`（`simulation/` 下脚本），部分脚本用 `multiprocessing` 并行。
- 真机：需要 Quafu 令牌。令牌只从环境变量 `QUAFU_API_TOKEN` 或包目录下的 `.env` 读取，**不在仓库中**（`.gitignore` 已排除 `.env`）。
